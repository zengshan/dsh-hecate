# Hecate · 赫卡忒

> **十几个会话，一屏看完。跑完的那个，会一直等你。**

*Session Console for DSH — 一个面板看住所有工作区的会话。*

[![npm](https://img.shields.io/npm/v/dsh-hecate.svg)](https://www.npmjs.com/package/dsh-hecate)
[![license](https://img.shields.io/npm/l/dsh-hecate.svg)](./LICENSE)

> **社区插件，非 DeepSeek 官方出品。** 名字里的 `dsh-` 只表示“为 DSH 写的”，不代表官方。
> *Community plugin — not affiliated with or endorsed by DeepSeek.*

**名字的来历**：赫卡忒是希腊神话里「三形一体」的神，站在三岔路口的守望者——举着火炬，告诉你哪条路上有人等你。这正是这个面板做的事：多个会话汇成一个入口，站在路口指路。夜色、火炬、岔路，也正好是这套 deep black + 霓虹的调性。

DSH 的跨工作区会话总览：谁在跑、谁在等你、谁刚跑完，一眼看完。悬停就能看它最后说了什么，点一下就切过去。

不读上下文、不做摘要、不自动批准、零 LLM 调用——只在你要看的时候，从本机读一条消息的尾巴。

---

## 它解决什么

开着七八个会话，切过去发现它早就跑完了，只是你没看见。刚聊完一个话题，它一结束就从列表里消失，只能凭记忆翻回去找。审批卡在某个后台会话里，二十分钟后你才想起来。

这个面板把这些收进一屏，按“谁需要你”排好，然后送你过去。

```
◈ 控制台
超时未处理
  ✓ 基金持仓周报        已 6 分钟未处理 · 基金   ← 红色，置顶
需要你看
  ⚠ 修 lint 报错        等你审批 · okx          2 分钟前
今天
  ● 战斗数值调整        运行中 · trunk          刚刚
```

## 三个细节

**刚跑完的，不会跑掉。**
DSH 里会话一结束就变“空闲”，回头就找不着了。这里会一直留着，直到你点卡片右上角的 `✓`——看过了，才收工。超过 5 分钟没处理，整张卡变红，升到页面最顶上。

**悬停就知道它最后说了什么。**
毛玻璃浮层跟着鼠标走，只显示它最新的一条回复，Markdown 正常渲染（表格、代码块、列表都在）。看完发现“就是这个”，鼠标移开继续扫；发现“得进去改”，点一下。

**它不碰你的上下文。**
不合并会话、不做摘要、不接管审批、不替你决定。预览读的是宿主已经折叠好的消息表面，不激活 Agent、不新建会话、不需要游标。

## 还有

- **分组阶梯**：超时未处理 → 需要你看 → 进行中 → 今天 → 更早
- **筛选**：进行中 / 全部，配 1 小时 / 今天（自然日）/ 本周（自然周）
- **顺手管理**：`＋` 新建（选工作区，不跳转）、`✎` 原地改名、`⤓` 归档
- **深夜配色**：deep black + 高对比霓虹；另有一套跟随宿主主题的皮肤
- **字号可调**：`A− / A+`，12–22px，整套面板等比缩放
- 卡片网格自适应，点卡片进入会话

## 安装

```
用 plugin_manager 安装 dsh-hecate
```

或从市场安装。第一次加载会在 `~/.dsh-hub` 建一个「控制台」工作区并排到侧栏最上面；如果你的 profile 里已经有标题为「控制台」的工作区，会**接管**它而不是新建。

配置（可选，写在 profile 的 `cordis.patch.yml` 该行下）：

```yaml
config:
  path: 'D:\my-hub'   # 控制台工作区目录，不存在会自动创建
  title: 控制台         # 仅首次创建时生效；界面也用它识别「◈ 控制台」分组
  pin: true            # 每次加载把它移到工作区列表最上面
```

## 设置

存在浏览器的 `localStorage`，不用改代码：

```js
localStorage.setItem('dsh-hecate:font', '17')    // 字号 12–22
localStorage.setItem('dsh-hecate:skin', 'host')  // night（默认）/ host
```

## 已知限制

- 卡片最多渲染 300 张（没有虚拟滚动），超出会提示「还有 N 个未显示」
- 完成时刻由面板观察 `running → 停止` 的边沿记录（宿主的会话摘要没有完成时间字段）；面板刚打开时，只有 5 分钟内动过的空闲会话会被补记成「刚跑完」
- 预览只对**有空闲权限**的会话可用；非回环地址访问预览接口会被拒绝（403）
- 卸载不会删除控制台工作区和上面三个 `localStorage` 键，需要手动清

## 开发

```
index.js           宿主半：控制台工作区、预览接口
client.js          浏览器半：数据层 / 皮肤 / 视图 / 组装 / 注册
cordis.patch.yml   插入一行 loader entry
locale/*.json      插件管理器与设置页显示的名字和描述
```

`client.js` 是六段结构，边界是硬的：字典 → 皮肤（只有 CSS 变量）→ 数据层 → 视图层（只吃算好的模型）→ 组装 → 注册。加皮肤只需在 `SKINS` 里补一组 `--sh-*` 变量；要改结构就在条目里给 `view`，数据层不用动。

打包：`npm pack`。没有构建步骤，没有运行时依赖。
